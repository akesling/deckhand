Playground

Write a deck on the left; the terminal presents it live — the same deckhand core, compiled to WebAssembly. Your draft is kept in this browser.

save / load via gist

Saving creates a secret gist through the GitHub API with your token — it needs only the gist scope (create one here) and never leaves your browser except to call GitHub. “Remember” stores it in this browser's localStorage. No token? copy markdown and paste at gist.github.com/new. Loading works token-free for public gists, including multi-file manifest gists (flattened into the editor).
