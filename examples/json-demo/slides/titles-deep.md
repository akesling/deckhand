## the title stays put

same theme, much more content — but the heading didn't move

- headings are always bold; `h1` / `h2` set their colors
- themes layer: user config, then the manifest's deck-wide `theme`,
  then per-slide entries like this one
- the same keys work in a ```` ```theme ```` fence inside any slide
  file, if you'd rather keep style next to content
- also themeable: `accent`, borders, margins, code colors,
  `qr_dark` / `qr_light`
